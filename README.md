# HOFÉ — CAFÉ & MARKET

Премиальное цифровое меню кафе с QR-меню по столам и админ-панелью управления контентом. Работает полностью без сервера: все данные хранятся локально в браузере (localStorage).

## Стек

React 18 · TypeScript · Vite · Tailwind CSS · React Router · React Hook Form · Zod · Zustand · Lucide React · qrcode

## Быстрый старт

```bash
npm install
cp .env.example .env   # затем задайте VITE_ADMIN_PASSWORD_HASH (см. ниже)
npm run dev
```

## Доступ администратора

Пароль администратора нигде не хранится в открытом виде — ни в коде, ни в README, ни в интерфейсе. В frontend попадает только SHA-256-хэш пароля через переменную окружения.

1. Придумайте надёжный пароль и вычислите его хэш:

```bash
node -e "const c=require('crypto');console.log(c.createHash('sha256').update('ВАШ_ПАРОЛЬ','utf8').digest('hex'))"
```

2. Впишите полученный хэш в `.env`:

```
VITE_ADMIN_PASSWORD_HASH=<хэш>
```

3. На странице `/admin/login` введите сам пароль. Смена пароля = замена хэша в `.env` и пересборка.

Хэш нельзя обратить обратно в пароль, а проверка выполняется на клиенте через Web Crypto API.

## Структура

- `/` — публичный сайт: Hero, Меню, О нас, Отзывы (переключатель RU/UZ).
- `/menu?table=N` — точка входа QR-меню: сайт определяет номер стола и показывает его гостю; номер автоматически передаётся с заказом.
- `/admin/login` — вход по паролю администратора (сессия в sessionStorage).
- `/admin` — дашборд со статистикой и быстрыми действиями.
- `/admin/menu` — CRUD товаров: поиск, фильтры, скрытие/показ, галерея изображений, удаление с подтверждением.
- `/admin/categories` — CRUD категорий с безопасным удалением.
- `/admin/reviews` — модерация отзывов: публикация/скрытие, редактирование, удаление, поиск и фильтры.
- `/admin/qr` — «QR-коды столов»: добавление/удаление столов, изменение номера, генерация и пересоздание QR-кодов, скачивание PNG, печать, открытие ссылки.
- `/admin/about`, `/admin/settings` — редактирование секций сайта и настроек.

## QR-меню по столам

1. В админке (`/admin/qr`) создайте столы — для каждого автоматически строится QR-код со ссылкой `/menu?table=N`.
2. Распечатайте коды и разместите на столах.
3. Гость сканирует код → открывается меню с плашкой «Стол №N» → при оформлении заказа номер стола передаётся вместе с заказом и виден администратору в разделе «Заказы».

## Данные и хранение

- Тестовые данные лежат в `src/data/` и загружаются при первом запуске.
- Все изменения из админки сохраняются в localStorage через сервисный слой:
  - `src/services/db.ts` — низкоуровневый доступ к localStorage;
  - `src/services/menuStorage.ts`, `categoryService.ts`, `reviewStorage.ts`, `orderStorage.ts`, `tableStorage.ts` — доменная логика;
  - `src/services/imageService.ts` — загруженные изображения сжимаются (canvas → JPEG) и сохраняются как data URL.
- Чтобы сбросить данные к тестовым — очистите ключи `hofe:*` в localStorage браузера.

## Безопасность

- Пароль администратора передаётся только в виде SHA-256-хэша через `VITE_ADMIN_PASSWORD_HASH`; исходный пароль отсутствует в репозитории и в собранном бандле.
- Флаг сессии хранится в sessionStorage и сбрасывается при закрытии вкладки.
- Это клиентская авторизация для демо/офлайн-использования: для публичного продакшена замените её на серверную аутентификацию.
